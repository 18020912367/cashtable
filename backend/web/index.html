核心功能

从截图到入账，只需一步

截图记账

支付/账单截图交给大模型视觉识别，自动提取金额、时间、分类与交易内容，一键入账。

自动记账（悬浮球入口）

系统截屏后点击悬浮球，App 自动读取相册最新截图识别入账，保存后自动删除截图并返回原界面，无需切换 App。

AI 自动分类

识别结果自动沉淀为分类规则，后续本地规则优先匹配，越用越准。

多记账人

无需登录，支持多个记账人，随时新增或删除，各记各的账。

收支统计与导出

按月、按分类查看收支统计；选择日期区间一键导出账单 CSV（含记账人与分类名），分享或保存。

激活码多设备共享

同一激活码可在多台设备重复激活，直接连接该激活码归属的云端账本，数据不会覆盖。

明细筛选

按分类、记账人、关键词快速筛选明细，随时找到想查的那笔账。

App 内更新

内置更新检查，固定连接云端，有新版本一键下载安装。

三种运行模式

本地单机、自有服务器、公共服务器，按需选择

本地模式（默认）

单机使用

App 自带全部功能与数据库，数据保存在手机中，适合个人记账。

  • 内置 sqlite 数据库
  • 截图识别直连大模型（自填 API Key）
  • 无需联网服务器
自定义模式

自有服务器

接入自己部署的服务器，多人共享同一数据库。

  • 填写服务器地址/端口/数据库目录
  • 多人记账
  • 数据在自有云端
全功能模式

公共服务器

输入激活码激活公共服务器，使用全部功能，开箱即用。

  • 激活码一键激活，支持多设备重复使用
  • 数据自动上传云端并每日备份
  • AI 识别走公共服务器

切换模式后，当前「记账人」会自动刷新为对应数据库中的第一个记账人，无需手动重新选择。

如何获取大模型 API Key（GLM 智谱）

本地模式使用截图 AI 识别前，需先配置自己的大模型 Key

访问智谱开放平台

浏览器打开 https://open.bigmodel.cn/，注册并登录账号（首次使用需完成实名认证）。

创建 API Key

左侧菜单进入「API Keys」，点击「创建新的 API Key」，复制以 sk- 开头的密钥。

填入 App 并验证

打开 App「我的 → LLM 设置」，粘贴 API Key（可修改 Base URL 与模型），点击「测试连接」确认连通。

开始使用

默认截图识别模型为 glm-4v-flash（视觉大模型），识别失败时系统自动切换备用模型。全功能模式激活后无需自备 Key。

常见问题

截图识别需要 API Key 吗？去哪获取？

本地模式需要自备大模型 Key：访问智谱开放平台 open.bigmodel.cn 注册并创建 API Key，填入「我的 → LLM 设置」。具体步骤见上方如何获取大模型 API Key。全功能模式激活后自动使用公共识别服务，无需自备。

截图识别不准确怎么办？

确保已正确填写大模型 API Key 并通过「测试连接」；截图尽量清晰、无遮挡，金额与商户信息完整。

如何激活全功能模式？

「我的 → 切换模式」选择全功能模式，输入 12 位激活码并「校验并激活」，首次激活会自动上传本地数据到云端。

同一激活码可以多个设备用吗？

可以。激活码支持重复使用：在多台设备输入同一激活码，会直接连接到该激活码已激活归属的公共数据库（不会覆盖已有数据），适合多设备共享同一账本。

检查更新提示无新版本？

更新检查固定连接云端（与运行模式无关）。0.8.0 及更早版本请先手动下载最新 APK 安装一次。

多人使用会冲突吗？

自定义/全功能模式为多人共享同一数据库，请错峰记账，避免同时写入造成冲突。

数据安全吗？

本地模式数据在手机；云端模式数据在服务器并每日备份。请妥善保管激活码与个人数据。
