# 截记（Cashtable）用户操作说明

> 截图即记账 —— 支持截图 AI 记账的记账小工具。

---

## 一、App 简介

「截记」是一款支持**截图 AI 记账**的记账小工具：

- 支付/账单截图交给大模型自动识别（金额、时间、分类、交易内容），一键入账
- 支持手动记账、悬浮球记账、自动记账多种方式
- 支持本地单机使用，也支持自建服务器多人记账、公共服务器激活使用

## 三、运行模式

App 默认**本地模式**，可在「我的 → 切换模式」中更改。

| 模式 | 说明 | 数据存储 | 截图识别 |
| --- | --- | --- | --- |
| **本地模式**（默认） | App 自带全部功能与数据库，单机使用 | 手机内置 sqlite | 直连大模型（在「我的 → LLM 设置」中维护 API Key） |
| **自定义模式** | 填写自有服务器地址/端口/数据库目录，多人记账 | 云端 sqlite | 走自有服务器 API |
| **全功能模式** | 输入激活码激活公共服务器，使用全部功能 | 云端 sqlite | 走公共服务器 API |

> 注意：自定义/全功能模式为多人共享同一数据库，**不支持多人同时操作**（存在写入冲突风险），请错峰记账。

> 提示：**切换模式后**，当前「记账人」会自动刷新为对应数据库中的**第一个记账人**，无需手动重新选择。

## 四、快速开始（本地模式）

1. 下载并安装 App，打开后默认进入本地模式
2. 点击底部「明细」页右下角 **+（记一笔）** 手动记账，或点击旁边的**相机图标**截图记账
3. 截图记账：选择一张支付/账单截图 → App 调用大模型识别 → 核对金额、分类、交易内容 → 确认入账
4. 如需 AI 识别，请先到「我的 → LLM 设置」填写自己的大模型 **API Key** 并测试连接

## 五、记账方式

### 1. 手动记账
- 「明细」页右下角 **+** 按钮
- 填写：类型（支出/收入）、金额、分类（可新增二级分类）、交易内容（可选）、记账人
- 保存后即入账

### 2. 截图记账
- 「明细」页右下角**相机图标**
- 选择支付/账单截图，大模型自动识别金额、时间、分类、交易内容
- 在确认页核对/修改后一键入账

### 3. 自动记账（悬浮球入口）
- 自动记账与悬浮球是**同一个功能**，悬浮球只是自动记账的入口
- 先使用手机**系统截屏**截取账单/支付界面（合规、无需额外权限）
- 在「我的 → 悬浮球记账」开启悬浮球后，任意界面点击悬浮球 → App 自动读取相册最新截图 → AI 识别 → 直达确认页入账
- 保存成功后**自动删除该截图**，并返回点击悬浮球前的界面
- 无需切换 App，适合频繁消费、追求效率的场景

## 六、明细管理

- 底部「明细」页展示全部账单，支持按**分类 / 记账人 / 关键词**筛选
- 点击某条记录可查看详情、**编辑**或**删除**
- 分类识别可由 AI 自动完成，并沉淀为分类规则，后续本地规则优先匹配

---

## 七、统计与账单导出

- 底部「统计」页
- 支持按月 / 按分类查看收支统计，帮助掌握消费结构
- **账单导出**：统计页右上角点击「导出」图标 → 选择开始/结束日期 → 一键导出该区间全部账单（CSV 文件）
  - CSV 每行包含：日期、类型、金额、**分类名**、**记账人名**、交易内容、来源、记录 ID、创建时间
  - 导出后可通过系统分享面板发送到微信/QQ/邮件或保存到文件管理器

---

## 八、记账人管理

- 「记一笔」页可切换记账人
- 支持**新增**记账人（输入姓名）与**删除**记账人
- 删除当前记账人后会自动引导重新选择

---

## 九、激活全功能模式

1. 「我的 → 切换模式」选择**全功能模式**
2. 输入**激活码**（12 位十六进制，向管理员获取），点击「校验并激活」
3. 首次激活会**自动将本地数据上传**到公共服务器（云端 sqlite）
4. 之后该 App 的所有数据与 AI 记账操作统一走公共服务器 API

> **激活码可重复使用**：同一激活码支持在多台设备上激活使用，重复激活会直接连接到该激活码已激活归属的公共数据库（**不会覆盖原有数据**），适合多设备共享同一账本。

---

## 十、自定义模式（自建服务器）

1. 「我的 → 切换模式」选择**自定义模式**
2. 先**下载标准 sqlite 模板**并导入自有服务器
3. 填写：服务器地址、端口（8000~8009）、服务器上 sqlite 目录
4. 连接成功后即可多人共享该服务器的数据库

---

## 十一、LLM 设置

### 1. 获取大模型 API Key（以 GLM 智谱为例）
1. 浏览器访问智谱 AI 开放平台：`https://open.bigmodel.cn/`
2. 注册并登录账号（首次使用需完成实名认证）
3. 左侧菜单进入「API Keys」，点击**创建新的 API Key**，复制以 `sk-` 开头的密钥
4. 打开 App「我的 → LLM 设置」，粘贴 API Key，可修改 Base URL 与模型，点击「测试连接」验证连通性

> 默认截图识别模型为 `glm-4v-flash`（视觉大模型），识别失败时系统自动切换备用模型。

### 2. Key 管理
- API Key 使用加密存储，界面只显示头尾，不可复制
- **全功能模式**下自动走公共服务器模型，Key 字段不可编辑

## 十三、数据与备份

- **本地模式**：数据保存在手机内置 sqlite 中，卸载 App 会清除，请注意定期备份
- **云端模式**：数据保存在服务器的租户目录中，服务端每日自动备份
- 建议重要数据定期手动备份

## 十四、常见问题（FAQ）

**Q1：检查更新提示"无新版本"？**
先确认手机网络可访问云端服务器（可先用浏览器打开官网首页测试）。0.8.0 及更早版本需手动下载 0.8.3 安装一次，之后更新检查固定走云端。

**Q2：截图识别不准确？**
请确认已填写正确的 LLM Key 且测试连接通过；截图尽量清晰、无遮挡、信息完整（金额、时间、商户）。

**Q3：激活失败？**
检查激活码输入是否正确（12 位十六进制，不含字母 O/数字 0 混淆）；确认激活码有效且未被停用；如仍失败请联系管理员。

**Q3-1：同一激活码可以多个设备用吗？**
可以。激活码支持重复使用，多台设备可共用同一账本（同一公共数据库），重复激活不会覆盖已有数据。

**Q4：多人同时使用提示数据冲突？**
自定义/全功能模式为多人共享同一数据库，请错峰记账，避免同时写入。

**Q5：如何删除记账人？**
「记一笔」页选择记账人时支持删除；删除当前记账人后重新选择即可。
